# Repository manifest

This repository contains the controlled R2 reproducibility package for manuscript `COMMAG-26-00412.R1`.

## Included

- Fixed experiment configuration.
- Optical-channel and learning code.
- Five random seeds.
- Trained checkpoints for all six compared methods.
- Per-seed and aggregate results.
- CDF samples and SNR-sweep tables.
- Vector figures generated from the archived results.
- Environment specifications.

## Provenance limitation

The original R1 submission did not include its historical simulation code, data, seeds, checkpoints, or logs. This repository contains the newly reconstructed and fixed R2 protocol used for the controlled experiments added in response to the final major-revision comments. It must not be represented as recovered historical code.
